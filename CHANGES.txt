DESIGN (iPhone style — implemented as an override layer, easy to revert):
  - System font stack (-apple-system/SF) with Arabic-safe letter-spacing rules
  - iOS palette: #F2F2F7 light / #000000 dark surfaces, #007AFF/#0A84FF blue,
    #34C759 green, #FF3B30 red, #FF9500 orange, hairline separators
  - Frosted-glass header + full-width bottom tab bar (saturate(180%) blur(20px))
  - Real iOS switches (green when on), gray-fill inputs, rounded cards,
    springy button press (scale .96), slimmer progress bars, iOS-style toast

PRACTICE FEEL (Duolingo-style, after every answer):
  - Bottom sheet slides up: green "ممتاز!"/"Excellent!" or red title,
    correct answer + Arabic meaning on wrong answers, "+N XP" float
  - Confetti burst on correct; gentle low buzz on wrong; fanfare on finish
  - Combo badge (flame ×N) from 3 correct answers in a row
  - Turtle button: word-by-word speech with one dot per word lighting up
    (can be turned off in More → Speech → "الصوت البطيء كلمة كلمة")

DEPLOYMENT NOTE (important):
  The old GitHub workflow (extract-lingostep-zip.yml) used `cp -an` which
  NEVER overwrites existing files — it left the repository a mix of old and
  new files (this caused the reported breakage). Follow docs/HOW-TO-UPDATE.md:
  upload the ZIP, run the old workflow once (registers the new sync workflow),
  then run "Sync LingoStep11 ZIP (overwrite all files)" once. After that the
  repository always matches the ZIP exactly and the old workflow is retired.
